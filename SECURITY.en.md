# Reporting a vulnerability

[Français](SECURITY.md) | [English](SECURITY.en.md)

Do not publish a vulnerability in an issue, a pull request or a discussion: it would be visible before it is fixed.

Report it through the disclosure process of the [Understand Tech Trust Center](https://trust.understand.tech). Give the version of AI in a Box (the commit or `release.env`), the steps to reproduce and the impact you observed.

We acknowledge the report, assess it and keep you informed until it is fixed. Please allow time for a fix before any publication.
