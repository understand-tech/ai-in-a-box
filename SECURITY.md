# Signaler une vulnérabilité

[Français](SECURITY.md) | [English](SECURITY.en.md)

Ne publiez pas une vulnérabilité dans une issue, une pull request ou une discussion : elle serait visible avant d'être corrigée.

Signalez-la par la procédure de divulgation du [Trust Center d'Understand Tech](https://trust.understand.tech). Indiquez la version d'AI in a Box (le commit ou `release.env`), les étapes pour reproduire et l'impact constaté.

Nous accusons réception, évaluons le signalement et vous tenons informé jusqu'à la correction. Merci de laisser le temps de corriger avant toute publication.
